# Inventory and Shopping Cart Manager

A Python-based Inventory and Shopping Cart Management System developed as a B.Tech CSE mini project at Budge Budge Institute of Technology (BBIT).

## Project Overview

This application combines product inventory management with shopping cart and billing operations through a menu-driven command-line interface.

## Features

- Add new products
- Display available products
- Search products by ID or name
- Update product information
- Delete product records
- Add and remove cart items
- Modify cart quantities
- Check stock availability
- Calculate shopping bills
- Update inventory after checkout confirmation

## Technologies Used

- Python 3.x
- Lists and Dictionaries
- Git
- GitHub
- Visual Studio Code
